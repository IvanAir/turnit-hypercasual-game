## 📝 О проекте
Моб-проект в жанре Casual Roguelike, разработанный на Unity.

* **Платформа:** WebGL / Android
* **Стек:** Unity, C#, Mobile SDK, URP
* **QA & Профилирование:** Проведена оптимизация Draw Calls (батчинг UI), проверка работы с памятью (0 B GC Alloc в кадре).
